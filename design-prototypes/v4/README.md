# 第四轮：像素场景式主页

打开 `index.html` 比较四个场景；预览图为实际浏览器截图。

| 版本 | 场景与构图 | 主操作 |
| --- | --- | --- |
| 星图 / astra.html | 星空与悬崖天文台；左侧观测终端，右侧建筑与功能标记 | 左侧 AI 输入、快捷操作、场景入口 |
| 晴港 / port.html | 浅海、群岛、灯塔与泊船；航图式资料标记 | 浅色对话面板、航图功能入口 |
| 档案室 / archive.html | 书架、窗景与书桌；对话区构成中央桌面终端 | 中央对话、书架标记、终端下方工具栏 |
| 苔原 / moss.html | 分层森林、池塘、树屋与精灵；左右分开的野外记录窗口 | 左侧工具索引、右侧 AI 输入 |

正文与标签使用正常字体；像素风集中在场景绘制、色块、边缘和图形细节。标题采用功能名称，不使用营销口号。账本默认持续保存，导入只用于补充资料；页面中“已保存”是演示状态。

全部图形由本地 Canvas 绘制，固定随机种子保持场景稳定，不依赖外部图片、字体或 CDN。星空、水纹和精灵等局部动态可暂停，浏览器减少动态效果设置默认关闭动画。

对话输入、提问建议、历史入口、功能弹窗、文件选择均可演示。文件不上传，输入不调用模型，不接入真实账本。原有前后端页面、组件和接口没有变动。

## 编辑与验证

- `build.py` 生成四个 HTML 和总览页面。
- `scene.js` 绘制四个独立场景。
- `style.css` 控制各版本布局与手机适配。
- `app.js` 实现静态交互。
- `verify.cjs` 使用仓库 Playwright 和本机 Chrome 检查桌面、手机、输入反馈、弹窗与文件选择，并保留截图。

已在 Chrome 的 1440×960、390×844 视口检查四个页面，修正了苔原标题与入口重叠及移动端场景横向溢出。四个页面均无 JavaScript 运行错误，原型交互验证通过。浏览器截图在同目录的 `*-preview.png`、`*-mobile.png` 和 `overview.png`。

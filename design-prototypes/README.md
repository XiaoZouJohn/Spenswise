# SpendWise 方向样板

直接在浏览器打开 `index.html`，再进入三个独立 HTML 样板。它们是静态交互原型，不连接真实账本或 DeepSeek，也不修改现有前后端接口和组件。

- **01 · 光晕**：浅色、克制、以一个问题为中心。
- **02 · 墨迹**：深色、编辑式排版、强调判断与证据。
- **03 · 潮汐**：有色动态背景、引导式三步操作。

三个样板均可切换中心步骤、输入问题并显示演示反馈；导入按钮只展示选中的文件名。请重点比较：哪一个让人愿意开始、哪一个更适合长期查看财务信息，以及哪一步仍显得费力。

## 04 · 开放工作台

`workspace.html` 是针对线性三步流程的下一轮探索。账本常驻、提问直接开始，账本、待处理、计划、家庭空间并列可达；导入只是需要补充数据时的一项操作。右侧抽屉展示各入口的角色，底部 Dock 提供常用入口。仍是静态演示，不读取真实数据。

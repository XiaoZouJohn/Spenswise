# 第三轮视觉样板

打开 `index.html` 比较四个方向。折光使用右侧曲面雕塑与左侧标题配重；手册使用纸本物件与两列提问布局；远景以全宽分层山形构成横向空间；构成将几何物件与右侧对话并列。

图形是本地 SVG，页面不依赖外部图片或字体。动画幅度受控，遵循减少动态效果设置。所有入口、对话反馈和文件选择均为静态交互演示，不接入真实数据。现有页面与接口未改动。

`build.py` 生成 HTML 与本地 SVG；`style.css` 和 `app.js` 控制页面与交互。使用仓库本地 Python 执行生成脚本即可重新生成页面。

已在本机 Chrome 中检查四个页面的桌面（1440×1000）和手机（390×844）视图，并验证发送反馈、功能弹窗、关闭操作及手机无横向溢出。对应 PNG 保留在本目录，便于比较。

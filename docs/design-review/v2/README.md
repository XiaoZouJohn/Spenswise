# 第二版界面核对

使用独立注册账号、独立 SQLite 数据库以及 `18086/5178` 端口。截图中的交易和记录仅属于隔离预览环境。

- [首页](home.png)：生活纪事、来源、继续阅读、建筑状态。
- [账房](ledger.png)：Story 常驻、待办、原有账册。
- [交易背景](transaction-background.png)：可选背景和关联记录。
- [集市](market.png)：消费回看、规则事件及日志。
- [账户详情](account-details.png)：快照与已关联流水。
- [月度回顾](review.png)：自然问题与草稿恢复。
- [生活记录](logs.png)：记录时间线与独立保存。
- [手机 Story](mobile-story.png)、[手机账房](mobile-ledger.png)：紧凑导航及内部滚动。

核对路径包含：从首页打开建筑、直接交易定位并保存背景、账户详情、回顾跨路由及刷新恢复草稿、无交易日志保存、移动端地点进入账房。桌面 1600×1000 与手机 390×844 的文档宽高未超过视口。

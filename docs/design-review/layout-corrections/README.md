# Story 与建筑布局修正

Story 保持挂载并持续显示。左侧固定440px，右侧工作区使用其余画布宽度，栏间距20px。画布首次打开时按文档实际可用宽度确定，之后改变窗口尺寸仅改变可见范围，不压缩容器。阅读区和工作区使用相同高度、独立滚动。助手展开时增加独立停靠空间。

外层尺寸修正：原先导航114px、主区上下内边距92px、面板高度（视口减170px）合计超过视口36px，导致无意义的纵向滚动；画布使用包含滚动条的 innerWidth 又引入轻微横向溢出。现采用文档 clientWidth/clientHeight，主区上下内边距合计56px，取消强制1500px最小画布和560px最小面板。浏览器读取1600×1000下的首页和账房，文档 scrollWidth/scrollHeight 均为1600×1000。

Story 取消展开和收起。顶部五阶段目录使用明显的阶段数字、当前阶段下划线及阅读提示。章节编号与标题并列，正文、事实金额和辅助说明分别保持层次。

建筑标签取消卡片、边框和图标，改为贴近建筑的文字标识，使用浅色描边确保场景上的可读性。高亮复用与视频坐标一致的场景图像，对建筑局部提亮。金额提示直接显示于关联区域，不使用矩形底板。分类金额来自当前分类汇总。

截图使用独立预览数据库和账号。本轮未运行测试，通过开发服务器采集评审截图。截图采集时记录到，1600×1000窗口中的 Story 内容尺寸为438×828px，工作区为1090×828px，缩至1200×800后两者保持相同尺寸，边框各占2px。

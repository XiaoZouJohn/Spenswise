# 富贵村 P2–P4 交付记录

## P2

账房保留筛选、审核、批量分类、撤销、删除与家庭归属。记一笔和 ImportPanel 进入独立抽屉。分类净支出来自服务层对全部筛选结果的 SQL 聚合，可点击下钻，分页不影响金额口径。新增 Page.category_spend，已重新生成 OpenAPI 客户端。

钱庄按现金账户、非现金资产、负债分组。资产负债共用金额轴，更新快照使用详情抽屉。沿用既有家庭覆盖、过期和共有账户规则，个人页面仍展示已记录范围。

## P3

集市采用条件与结果双栏。保存方案位于结果区域，条件修改、账本版本变化或查看历史方案时提示结果来源并阻止误保存。保留自然月、保护类别、周期账单、优化和依据入口。

政务中心按月份编辑缘由、下一阶段约束和事实差异。保存时记录服务端事实、账本版本和盘点修订号。支持重新读取、删除及基于已保存版本提问。未保存草稿在当前会话内随路由保留，重新打开浏览器需读取已保存案卷。

案卷使用现有 Setting 表，键为 monthly_review:YYYY-MM，主键同时包含 owner_id。沿用账号导出与注销，没有新增表或 Alembic 迁移。删除清空内容并保留递增版本号，避免旧窗口覆盖重新创建的盘点。更新使用版本比较和数据库条件更新，冲突返回409。自由文本金额不参与财务计算。

新增接口为 GET/PUT /api/monthly-reviews/{month} 与 POST /api/monthly-reviews/{month}/clear。服务逻辑位于 monthly_review.py。盘点键从财务版本摘要中排除，保存文字不触发预测重算。

## P4

使用已有 Motion 库处理工作区进入和退出，保持单个 AI 会话实例。抽屉和助手轻量滑入，返回 Story 恢复建筑入口焦点。视频、热点与输入独立，减少动态效果时关闭转场。消费模拟与记账草稿保存在按账号隔离的查询缓存中，退出账号时随现有缓存清理。

背景运动沿用原视频。建筑关系继续使用真实金额和关联聚焦。逐账户资金路径仍缺少可核实数据，本轮没有添加装饰性流动线或几何图标动画。
